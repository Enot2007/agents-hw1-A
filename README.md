Мини-трекер учебных задач разработан двумя способами в двух отдельных диалогах с одной моделью: по короткому прямому запросу (V1) и по спецификации в формате OpenSpec (V2).

## Состав репозитория

| Файл или каталог | Содержание |
|---|---|
| `tracker-v1.html` | V1 — исходная версия по прямому запросу |
| `tracker-v1-fix1.html` | V1 после исправления дефекта проверки ввода (T4) |
| `tracker-v2.html` | V2 — версия по спецификации |
| `spec/` | спецификация: `proposal.md`, `specs/tracker/spec.md`, `design.md`, `tasks.md` |
| `prompts.txt` | тексты запросов: прямой запрос, запрос спецификации, запрос реализации, исправление |
| `REPORT.md` | отчёт: методика, результаты T1–T5, дефект и исправление, метрики, вывод |
| `screenshots/` | снимки экрана: обе версии на ширине 390 px; дефект T4 до и после исправления |
| `chats/` | полные ответы модели в обоих диалогах |
| `logs/` | журналы проверок и хронология запросов |
| `qa/` | сценарии автоматической проверки T1–T5 |

## Запуск

Скачайте нужный HTML-файл (на странице файла — кнопка «Download raw file») и откройте его в браузере. Сервер, установка зависимостей и подключение к интернету не требуются.

Для возврата к исходным данным выполните в консоли браузера `localStorage.clear(); location.reload()`.
