# Proposal: мини-трекер учебных задач на неделю

## Why

Нужен простой автономный инструмент, чтобы планировать учебные задачи на неделю и видеть прогресс в часах. Он должен работать без сети, CDN, внешних библиотек и API-ключей. Прогресс должен считаться правильно и не зависеть от фильтра.

## What Changes

- Добавляется мини-трекер. Задача содержит поля `id`, `title`, `hours`, `done`.
- Пользователь может добавить задачу, удалить её и переключить `done`. Эти действия меняют данные приложения, а не только разметку.
- Ввод проверяется: название после trim непустое; часы от 0,5 до 24 с шагом 0,5; пустое поле не считается нулём. Ошибка показывается рядом с полем, введённые значения не стираются.
- Итоги: всего часов, выполнено часов, прогресс = round(100 × done / total). Без задач прогресс равен 0%.
- Фильтр меняет только видимый список. Итоги всегда считаются по всем задачам.
- Стартовый пример: «Чтение» 2 ч (done), «Практика» 4 ч, «Повторение» 2 ч. Всего 8 ч, выполнено 2 ч, прогресс 25%.
- Интерфейс читается на ширине 390 px без горизонтального скролла. У всех полей и кнопок есть подписи.
- Необязательно: сохранение в localStorage. Если хранилище недоступно, показывается понятное сообщение, а работа продолжается в памяти.

Есть два варианта поставки, их результат одинаков:
- **A** — один файл `tracker-v2.html`, CSS и JavaScript встроены в него.
- **B** — файлы `index.html`, `styles.css`, `app.mjs`, `domain.mjs`, `tests/acceptance.test.mjs`.

## Capabilities

### New Capabilities
- `tracker`: управление списком учебных задач, валидация ввода, расчёт итогов и прогресса, фильтр видимого списка, адаптивный доступный интерфейс, необязательное локальное сохранение.

### Modified Capabilities
- нет

## Границы (Non-goals)

- Нет сервера, синхронизации, авторизации, аккаунтов и сетевых запросов.
- Не делаем редактирование названия или часов у существующей задачи, сортировку, перетаскивание, даты, дедлайны, категории, несколько недель.
- Фильтр ограничен значениями «Все» и «Активные». Другие значения не требуются.
- Не подключаем сборщики, фреймворки, внешние тестовые библиотеки и CDN.
- На этом этапе пишутся только документы. Код пишется отдельным запросом.

## Impact

- Новые файлы: `tracker-v2.html` в варианте A или пять файлов варианта B.
- Зависимости: нет. Для тестов варианта B используется встроенный `node:test` (Node.js 18+).
- Вариант A открывается напрямую из файла. Варианту B нужен локальный статический сервер, потому что ES-модули через `file://` браузеры блокируют (см. design.md).
